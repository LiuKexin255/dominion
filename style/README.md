## 外部引用规范

文档中引用外部规范时，遵循以下约定：

* **保留原入口作为索引**：原始链接保留在正文或 `## 引用` 区块顶部，作为该规范的入口索引。
* **展开具体规范**：在索引下方列出具体规范的标题与直链，避免读者二次跳转（即链接点开就是实际要看的内容）。
* **使用原文档标题**：尽量沿用外部文档自身的标题（包括章节标题、AIP 编号+标题等），不改写、不意译。
* **直链到最终内容**：链接应指向最终内容页（子文档、单条规范、章节锚点），而非只跳到站点的导航/索引页。
* **按官方结构组织**：若外部规范自身有分类（如 AIP 的 10 个类别、Go Style 的三份文档），按其官方结构分组列出。

参考实现：`golang.md`、`api.md`、`javascript.md` 的 `## 引用` 区块。
