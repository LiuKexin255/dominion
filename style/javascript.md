# javascript/typescript 规范

* 以 [Google TypeScript Style](https://google.github.io/styleguide/tsguide.html) 作为本仓库 js/ts 规范。

## 引用

> 外部规范引用，可作为规范参考。入口索引：[Google TypeScript Style Guide](https://google.github.io/styleguide/tsguide.html)。以下为该指南的 9 个顶级章节，可直接跳转到对应章节。

* [Introduction](https://google.github.io/styleguide/tsguide.html#introduction) — 术语约定（RFC 2119）、示例说明。
* [Source file basics](https://google.github.io/styleguide/tsguide.html#source-file-basics) — 文件编码（UTF-8）、空白字符、转义序列、非 ASCII 字符。
* [Source file structure](https://google.github.io/styleguide/tsguide.html#source-file-structure) — 版权信息、`@fileoverview`、import / export 规则、模块与命名空间。
* [Language features](https://google.github.io/styleguide/tsguide.html#language-features) — 变量声明、数组 / 对象字面量、类、函数、控制语句、字面量等语言特性约束。
* [Naming](https://google.github.io/styleguide/tsguide.html#naming) — 各类标识符（变量、函数、类、文件等）的命名规则。
* [Type system](https://google.github.io/styleguide/tsguide.html#type-system) — 类型注解、类型推断、可空类型、联合类型等类型系统规则。
* [Toolchain requirements](https://google.github.io/styleguide/tsguide.html#toolchain-requirements) — TypeScript 编译器版本与配置要求。
* [Comments and documentation](https://google.github.io/styleguide/tsguide.html#comments-documentation) — 注释类型、JSDoc 用法、参数文档。
* [Policies](https://google.github.io/styleguide/tsguide.html#policies) — 团队约定、不遵守规范时的处理、格式化策略等。
