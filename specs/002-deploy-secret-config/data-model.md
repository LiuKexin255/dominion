# Data Model: Deploy Secret Configuration

**Branch**: `002-deploy-secret-config` | **Date**: 2026-06-02

## Entities

### 1. Logical Secret Declaration (service config 层)

服务 artifact 声明的 secret 需求，标识为稳定的逻辑名称。

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| name | `string` | 非空，匹配 `^[a-z][a-z0-9_-]{0,63}$`，在同一个 artifact 内唯一 | 逻辑 secret 名，作为运行时文件名 |

**Validation Rules**:
- VR-SD-1: 空字符串 → 拒绝
- VR-SD-2: 不匹配 name pattern → 拒绝
- VR-SD-3: 同一 artifact 内重复 → 拒绝
- VR-SD-4: 标准化后路径冲突（如 `foo-bar` 和 `foo_bar` 不冲突，但 `/../etc` 被 pattern 拒绝）→ 由 pattern 保证

**Storage**: `service.yaml` → `artifacts[].secrets[]`

**State Transitions**: 无。声明是静态的。

### 2. Secret Binding (deploy config 层)

环境特定的映射，从逻辑 secret 名到 Kubernetes Secret + key。

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| logical_name | `string` | 非空，对应某个已声明的 secret name | 逻辑 secret 名（YAML map key） |
| secret | `string` | 非空 | Kubernetes Secret 资源名 |
| key | `string` | 非空 | Kubernetes Secret 中的 key |

**Validation Rules**:
- VR-SB-1: logical_name 必须在关联 service artifact 的 secrets 列表中存在
- VR-SB-2: secret 和 key 均不可为空
- VR-SB-3: artifact 声明的每个 secret 都必须有一个 binding（完整性校验）
- VR-SB-4: binding 的 logical_name 不能多于声明的 secrets（无多余绑定）

**Storage**: `deploy.yaml` → `services[].artifact.secrets{}`

**State Transitions**: 无。绑定是静态的。

### 3. Secret Binding (proto / domain 层)

通过 protobuf 传递到 deploy service 的绑定信息。

| Field | Type | Proto Field # | Description |
|-------|------|---------------|-------------|
| logical_name | `string` | 1 | 逻辑 secret 名 |
| secret_name | `string` | 2 | Kubernetes Secret 资源名 |
| key | `string` | 3 | Kubernetes Secret 中的 key |

**Parent**: `ArtifactSpec.secret_bindings` (field 12)

### 4. Secret Runtime Contract (K8s 层)

运行时实际注入到容器的 secret 挂载。

| Resource | Description |
|----------|-------------|
| Volume `dominion-secrets` | ProjectedVolume，包含所有 binding 的 SecretProjection |
| VolumeMount `/mnt/dominion/secret` | 只读挂载，每个 binding 映射为 `{Path: logical_name}` |
| EnvVar `DOMINION_SECRET_DIR` | 值 `/mnt/dominion/secret`，平台强制注入 |

**Generated By**: `builder.go` → `BuildDeployment` / `BuildStatefulSet`

**Conditions**:
- 仅当 artifact 有至少一个 secret binding 时创建
- 无 bindings 时不创建 volume/mount/env
